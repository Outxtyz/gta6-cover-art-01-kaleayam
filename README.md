An offline web app that turns your photo and a caption into GTA 6-style cover art: multi-panel poster layouts, a Vice City sunset/neon grade, and PNG export in 1080x1080, 1080x1350 and 1920x1080. Built for the make.fun gta6-cover-art-01 bounty as @kaleayam. Everything is original — no Rockstar logo, artwork or fonts.
